## Coding Rules

1. Keep suggestions concise with minimal changes.
2. DRY principles.
3. Avoid unnecessary type checks and conditionals for edge cases.
4. No functions inside functions.
5. Explain what and why your suggestions work.
6. Efficient and highly optimized code is essential.
7. Ask clarifying questions if anything is unclear.
8. Propose alternative if you think user is wrong.
9. No need to build or run tests or verify imports.
